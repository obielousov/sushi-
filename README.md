# Qitchen — Sushi Restaurant Website

A responsive multi-page website for a premium sushi restaurant, created as a frontend portfolio project. The website features a modern UI, smooth animations, responsive design, and an intuitive user experience across all devices.

## Live Demo

https://obielousov.github.io/sushi-/

## Features

- Responsive multi-page layout: Home, Menu, About, Reservation, Contact and Blog pages;
- Semantic HTML5 markup;
- Accessibility support (`aria-*`, landmarks, descriptive alt texts);
- Interactive reservation form with date picker;
- Custom animated preloader and cinematic hero entrance animations;
- Smooth scroll-triggered entrance animations;
- Custom mobile burger navigation;
- Lazy-loaded WebP images with `srcset`;
- SEO-friendly meta tags and Open Graph support;
- Optimized production build with Vite.

## Tech Stack

- HTML5
- SCSS
- Vanilla JavaScript
- Vite
- PostHTML

## Run Locally

Clone the repository:

```bash
git clone https://obielousov.github.io/sushi-.git
```

Open `index.html` in any modern browser.

No installation or build process is required.
